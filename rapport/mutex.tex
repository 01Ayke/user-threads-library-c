\section{Mutex}
Les mutex sont un composant important permettant une exécution des threads sur des données partagées. Nous allons voir dans cette partie notre gestion de ces derniers.
\subsection{Architecture}
Notre choix pour représenter la file d'attente des threads sur une donnée bloquée par un mutex s'est aussi porté sur une file doublement chaînée.
Ce choix a été porté par l'idée d'une implémentation permettant un système de priorité entre les threads sur la donnée. Comme dit précédemment, une file doublement chaînée
permettrait une manipulation en temps constant.
L'implémentation dans la librairie suit la même logique que la file décrite en \ref{sec:files_dattente}.
