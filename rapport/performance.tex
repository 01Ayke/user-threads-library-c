\section{Performances}

\subsection{Protocole de mesure}
Nous avons mesuré les performances uniquement sur les tests pertinents. Ces tests comparent notamment les performances de notre librairie, à celle de pthread.

Pour chaque test, nous lançons 3 executions et nous conservons la médiane des relevés afin de fournir un résultat moins sensible au bruit.
Les mesures ci-dessous correspondent à la configuration :
\texttt{threads=64} et \texttt{yields=1000} quand applicable dans le test.

\subsection{Analyse}
Ces mesures montrent que notre implémentation est déjà compétitive sur plusieurs cas
(21, 22, 23, 32, 61), ce qui est cohérent avec un ordonnancement en espace utilisateur
et un coût de commutation faible.
En revanche, les tests 33 et 62 restent des points faibles : ils semblent plus sensibles
à nos choix de structures de données et au coût des parcours quand le nombre de threads
augmente.

Cette section sera consolidée pour le rapport final avec :
\begin{itemize}
  \item des courbes pour plusieurs tailles de charge (variation du nombre de threads) ;
  \item une description précise de la machine utilisée (CPU/coeurs) ;
  \item une analyse ciblée des régressions (en particulier sur 33 et 62).
\end{itemize}
